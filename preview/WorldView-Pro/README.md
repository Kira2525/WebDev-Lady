# WorldView Pro

WorldView Pro is a premium static HTML website template built around a cinematic animated Earth background, polished glass UI, responsive layouts, and marketplace-ready documentation.

## Template Overview

WorldView Pro is designed for travel brands, SaaS products, technology startups, education platforms, agencies, and globally positioned businesses that want a dramatic first impression without taking on a complex framework.

The package includes a complete public page set, branded assets, responsive navigation, refined animations, commercial template licensing, and step-by-step setup and customization docs.

## Features

- Premium animated Earth scene with softer cloud layers, stronger atmosphere glow, and slower movement
- Responsive desktop, tablet, and mobile layouts
- Accessible navigation with mobile hamburger menu and keyboard support
- CTA flows for pricing, contact, setup help, custom branding, and thank-you states
- Subtle scroll reveal, cursor glow, and card tilt interactions
- Shared CSS design system with reusable cards, panels, lists, and CTA sections
- Buyer-focused FAQ, showcase, pricing, and documentation pages
- Commercial-use license summary for template sales and client work

## Installation

1. Download or copy the template files into your project folder.
2. Open `index.html` in your browser to preview the site locally.
3. Edit the HTML files directly to replace your text, links, and section content.
4. Update branding assets in `assets/`.
5. Upload the full folder to your static hosting provider when you are ready to publish.

See [docs/setup-guide.md](docs/setup-guide.md) for a fuller publishing workflow.

## Customization

Common edits include:

- Replacing the logo and favicon in `assets/`
- Updating color tokens in `css/styles.css`
- Editing copy in each HTML page
- Changing CTA destinations in page button links
- Connecting the contact form to your preferred form provider

See [docs/customization-guide.md](docs/customization-guide.md) for step-by-step instructions.

## Browser Support

WorldView Pro is built for current versions of:

- Chrome
- Edge
- Firefox
- Safari

Older browsers may still render the layout, but advanced blur and motion effects can appear simpler.
