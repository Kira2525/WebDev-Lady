# Rain Blossom
# Setup Guide

Thank you for purchasing the Rain Blossom Website Template!

This guide will walk you through setting up your website and preparing it for launch.

---

# Requirements

You only need:

- A web hosting account
- A domain name (optional)
- A code editor (Visual Studio Code recommended)
- A modern web browser

No frameworks or build tools are required.

---

# Folder Structure

```
RainBlossom/
```

---

# Step 1
## Extract the Template

If the template is downloaded as a ZIP file:

• Right-click the ZIP file.

• Select **Extract All**.

You should now have the RainBlossom project folder.

---

# Step 2
## Open the Project

Open the project folder using your favorite code editor.

Recommended:

Visual Studio Code

---

# Step 3
## Preview the Website

If using Visual Studio Code:

Install the **Live Server** extension.

Right-click:

```
index.html
```

Choose:

```
Open with Live Server
```

The website will open in your browser.

---

# Step 4
## Replace the Demo Content

Before publishing, update:

- Business Name
- Logo
- Images
- Videos
- Contact Information
- Social Media Links
- Text Content
- Testimonials
- Packages
- FAQ
- SEO Information

See the included **Customization Guide** for details.

---

# Step 5
## Replace Images

Replace the images inside:

```
assets/images/
```

You can keep the same filenames or update the HTML if you rename them.

---

# Step 6
## Replace the Hero Video

Replace:

```
assets/videos/rain-blossom-hero.mp4
```

with your own MP4 video.

---

# Step 7
## Connect the Contact Form

By default, the contact form redirects to:

```
thank-you.html
```

To receive inquiries, connect the form to a service such as:

- Formspree
- Netlify Forms
- Getform
- Basin
- Custom PHP

See the included **Form Setup Guide**.

---

# Step 8
## Update SEO

Every page contains:

- Title
- Meta Description
- Open Graph Tags
- Twitter Cards

Replace the demo information with your own.

---

# Step 9
## Update the Manifest

Open:

```
site.webmanifest
```

Update:

- Business Name
- Description
- Theme Color
- Icons

---

# Step 10
## Update robots.txt

Open:

```
robots.txt
```

Replace:

```
https://yourdomain.com
```

with your website address.

Example:

```
User-agent: *

Allow: /

Sitemap: https://yourdomain.com/sitemap.xml
```

---

# Step 11
## Update sitemap.xml

Replace every occurrence of:

```
https://yourdomain.com
```

with your own domain.

Example:

```
https://example.com
```

---

# Step 12
## Test the Website

Before publishing, check:

✔ Every page opens correctly

✔ Navigation works

✔ Images display correctly

✔ Hero video plays

✔ Contact form works

✔ Mobile menu works

✔ Tablet layout works

✔ Desktop layout works

✔ Social media links work

✔ Footer links work

✔ No broken images

✔ No broken links

---

# Step 13
## Upload to Your Web Host

Upload every file and folder to your website's public directory.

Examples:

```
public_html/
```

or

```
www/
```

or

```
htdocs/
```

depending on your hosting provider.
