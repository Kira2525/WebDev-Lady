# 2. Change Your Business Name

Search the project for:

```
Rain Blossom
```

Replace it with your business name.

Example:

```
Rain Blossom

↓

Evergreen Estate
```

---

# 3. Replace the Logo

Replace:

```
assets/images/logo.jpg
```

Recommended:

- PNG
- Transparent background
- Around 300px wide

---

# 4. Change the Favicon

Replace:

```
assets/images/favicon.png
assets/images/favicon.svg
```

Recommended sizes:

- 32×32
- 192×192
- 512×512

---

# 5. Replace Images

All images are inside:

```
assets/images/
```

Replace them with your own.

You can either:

• Keep the same filenames

OR

• Change the filenames inside the HTML pages.

---

# 6. Replace the Hero Video

Replace:

```
assets/videos/rain-blossom-hero.mp4
```

Recommended:

- MP4
- 1080p
- Under 20MB
- 15–30 seconds
- Muted

---

# 7. Change Colors

Open:

```
css/style.css
```

Near the top you'll find:

```css
:root{

--green:
--gold:
--cream:
--black:

}
```

Changing these colors updates the entire website.

---

# 8. Edit Text

Open any HTML page.

Replace:

• Headlines

• Paragraphs

• Button text

• Services

• Venue descriptions

• Reviews

• FAQ

Everything is clearly labeled inside the HTML.

---

# 9. Update Navigation

Navigation appears near the top of every page.

Example:

```html
<nav class="desktop-nav">
```

Edit the links as needed.

# 11. Change Social Media Links

# 12. Contact Form

The demo form redirects to:

```
thank-you.html
```

To receive real inquiries connect it to:

• Formspree

• Netlify Forms

• Basin

• Getform

• Your own backend

# 13. Edit SEO

Each page contains:

```
<title>

<meta name="description">

Open Graph tags

Twitter tags
```

Replace these with information for your own business.
