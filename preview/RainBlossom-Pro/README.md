# Rain Blossom
### Luxury Garden Wedding & Event Website Template

Rain Blossom is a fully responsive HTML5 website template designed for wedding venues, event venues, gardens, estates, and luxury event businesses.

The template is built using plain HTML, CSS, and JavaScript, making it fast, lightweight, and easy to customize without any frameworks.

---

# Features

- Fully Responsive Design
- Desktop, Tablet & Mobile Layouts
- Sticky Navigation
- Animated Mobile Menu
- Full Screen Video Hero
- CSS Scroll Animations
- FAQ Accordion
- Contact Form
- Dedicated Thank You Page
- Gallery Page
- Testimonials Page
- Venue Spaces Page
- Package Page

# Customizing the Template

## Change the Logo

Replace:

```
assets/images/logo.jpg
```

with your own logo.

---

## Change the Favicon

Replace:

```
assets/images/favicon.png
```

---

## Change the Brand Name

Search for:

```
Rain Blossom
```

Replace it with your business name.

---

## Change the Tagline

Search for:

```
Garden Weddings & Events
```

Replace it with your own tagline.

---

## Change Colors

Open:

```
css/style.css
```

At the top of the file you'll find the color variables.

Example:

```css
:root{
  --gold:;
  --cream:;
  --green:;
}
```

Change these values to instantly update the entire website.

---

## Replace Images

All images are located in:

```
assets/images/
```

Simply replace the image files while keeping the same filenames, or update the image paths inside the HTML pages.

---

## Replace the Hero Video

Replace:

```
assets/videos/rain-blossom-hero.mp4
```

or edit the video source inside each page.

---

## Edit Text

Open any HTML page and replace the demo content with your own.

Examples:

- Business name
- Headlines
- Paragraphs
- Services
- Packages
- Reviews
- FAQ
- Contact Information

---

## Update Contact Information

Search for:

```
(555) 019-2840
hello@rainblossom.com
Meadowbrook Valley
```

Replace them with your own business details.

---

## Change Social Media Links

Near the bottom of every page you'll find:

```
https://facebook.com
https://instagram.com
https://pinterest.com
https://tiktok.com
```

Replace these with your own social media profiles.

---

## Contact Form

The demo form currently redirects to:

```
thank-you.html
```

To make the contact form send emails, connect it to:

- Formspree
- Netlify Forms
- Basin
- Getform
- Your own backend
