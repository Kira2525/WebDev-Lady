# CosmicOrbit Pro

CosmicOrbit Pro is a premium multi-page HTML website template for SaaS, startup, software, and digital product brands. It combines a Three.js space scene with polished marketing pages, a contact flow, a login demo, and a dashboard demo in a framework-free package.

## Included Pages

- `index.html`
- `about.html`
- `pricing.html`
- `contact.html`
- `login.html`
- `dashboard.html`
- `coming-soon.html`
- `404.html`

## Stack

- HTML5
- CSS3
- JavaScript
- Three.js via CDN import map

## Quick Start

1. Open the project folder in your code editor.
2. Run the site through a local server such as VS Code Live Server.
3. Open `index.html`.

## Important Notes

- `login.html` and `dashboard.html` are front-end demo pages only.
- `coming-soon.html` is set up as a polished checkout placeholder or handoff page.
- The contact form uses demo behavior in `js/main.js` and should be connected to a real form service before launch.
- Google Fonts and the Three.js module load from external CDNs by default.

Additional setup, customization, and licensing notes are in `docs/`.
