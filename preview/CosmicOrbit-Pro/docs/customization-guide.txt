COSMICORBIT PRO CUSTOMIZATION GUIDE

BRAND NAME

Open any HTML page and update the text:

CosmicOrbit Pro

Replace it with your own product or company name.

COLORS AND VISUAL TOKENS

Open:

`css/style.css`

Edit the variables inside `:root` to change:

- Background colors
- Accent colors
- Border colors
- Text colors
- Radius and shadow values

TYPOGRAPHY

The template uses Space Grotesk from Google Fonts.

If you want to self-host or switch fonts:

1. Update the font links in the `<head>` of each HTML page.
2. Update `--font-body` in `css/style.css`.

TEXT CONTENT

All primary copy is directly editable inside the HTML files.

Recommended pages to update first:

- `index.html`
- `about.html`
- `pricing.html`
- `contact.html`

BUTTON LINKS

Current sales flow:

- Template purchase buttons -> `coming-soon.html`
- Custom branding buttons -> `contact.html#custom`

Update those links to match your live checkout and inquiry process when needed.

CHECKOUT PAGE

`coming-soon.html` is now written as a checkout placeholder or cart handoff page.

You can:

- Keep the page and connect it to a real payment provider
- Replace purchase links with a direct Stripe, PayPal, Gumroad, or Lemon Squeezy URL
- Duplicate the page into a custom `cart.html` if your storefront needs a different path

CONTACT FORM

The form in `contact.html` uses demo behavior from:

`js/main.js`

Current behavior:

- Prevents real submission
- Shows a success message
- Resets the form

Connect it to a real endpoint before launch.

THREE.JS BACKGROUND

The animated space scene is controlled by:

`js/space-scene.js`

You can customize:

- Planet placement
- Light colors
- Star density
- Motion intensity
- Mobile behavior

RESPONSIVE DESIGN

Desktop styles:

`css/style.css`

Tablet overrides:

`css/tablet.css`

Mobile overrides:

`css/mobile.css`

SCREENSHOTS AND PREVIEWS

Preview images are stored in:

`assets/images/`

Replace these with your own screenshots if you are selling a branded version.

SEO

Each page includes its own title and meta description.

Update those tags in every HTML page if you change the brand, niche, or offer.
