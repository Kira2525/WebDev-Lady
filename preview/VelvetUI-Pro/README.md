# VelvetUI Pro

VelvetUI Pro is a premium multi-page website template built with vanilla HTML, CSS, and JavaScript. It includes a polished glassmorphism design system, an animated diamond text hero, responsive layouts, reusable marketing sections, and supporting pages for modern digital brands.

## Included pages

- `index.html`
- `about.html`
- `features.html`
- `pricing.html`
- `showcase.html`
- `faq.html`
- `contact.html`
- `thank-you.html`
- `404.html`

## Quick start

1. Open `index.html` directly in a browser, or serve the folder with any static file server.
2. Update page copy inside the HTML files.
3. Adjust colors, spacing, and shared components in `css/styles.css`.
4. Edit the animated hero words in `js/script.js`.
5. Connect the contact form in `contact.html` to Formspree, Netlify Forms, or your own backend.

## Core editing points

- Brand copy and meta content: each HTML page
- Shared styling: `css/styles.css`
- Animated diamond text and mobile nav: `js/script.js`
- Contact form behavior: `contact.html`

## Notes

- The canvas animation only runs on pages that include `<canvas id="heroCanvas"></canvas>`.
- Pages without the canvas still load safely with the shared JavaScript.
- Demo pricing and FAQ content are placeholders intended for buyer customization.
