# VELVET STUDIO Website

This project contains a polished static website for VELVET STUDIO, a fictional interior design studio. The site is built with HTML, CSS, JavaScript, and local image assets, so it can be hosted on any static web server without a framework build step.

## Pages

* `index.html` - Studio homepage
* `about.html` - Studio story and values
* `services.html` - Service offerings
* `features.html` - Process and approach
* `pricing.html` - Investment options
* `portfolio.html` - Selected project stories
* `faq.html` - Common client questions
* `contact.html` - Inquiry form
* `thank-you.html` - Inquiry confirmation
* `404.html` - Missing page experience

## Structure

* `css/styles.css` - Main visual system and shared page styles
* `css/tablet.css` - Tablet layout refinements
* `css/mobile.css` - Compact navigation and mobile layout refinements
* `js/script.js` - Navigation, FAQ, reveal motion, form redirect, and canvas effects
* `assets/img/` - Logo, favicon, social artwork, and editorial imagery
* `docs/` - Website handoff, launch, hosting, form, and image notes

## Local Review

Open `index.html` in a browser, or serve the folder with a local static server. Review every page at desktop, tablet, and phone widths. The compact navigation switches to the diamond logo button on smaller screens.

## Launch Notes

The metadata uses `https://velvetstudio.example` as the fictional business domain. Update it only when a real domain is assigned. The contact form currently uses a static redirect to `thank-you.html`; connect a form provider or backend before collecting real inquiries.
