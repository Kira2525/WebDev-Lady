# WorldView Global Pro Setup Guide

## Welcome

Thank you for purchasing WorldView Global Pro.

WorldView Global Pro is a premium static website template built with clean HTML, CSS, JavaScript, SVG assets, and responsive layouts.

No frameworks, package managers, build tools, or server-side software are required.

The website can be edited with:

* Visual Studio Code
* Sublime Text
* Notepad++
* Cursor
* Any HTML editor

---

# What's Included

The template package includes:

```text
/
├── index.html
├── about.html
├── solutions.html
├── showcase.html
├── use-cases.html
├── faq.html
├── pricing.html
├── contact.html
├── thank-you.html
├── 404.html
│
├── assets/
│
├── css/
│   ├── styles.css
│   ├── tablet.css
│   └── mobile.css
│
├── js/
│   └── script.js
│
├── docs/
│   ├── setup-guide.md
│   ├── customization-guide.md
│   ├── hosting-guide.md
│   ├── form-setup-guide.md
│   └── image-replacement-guide.md
│
├── robots.txt
├── sitemap.xml
└── site.webmanifest
```

---

# Included Pages

WorldView Global Pro includes:

| Page           | Purpose                        |
| -------------- | ------------------------------ |
| index.html     | Homepage                       |
| about.html     | Company overview               |
| solutions.html | Services and solutions         |
| showcase.html  | Featured projects and examples |

| thank-you.html | Form success page              |
| 404.html       | Custom error page              |

---

# System Requirements

Requirements are minimal.

You only need:

* A modern web browser
* A text editor
* Optional hosting account

Compatible browsers:

* Chrome
* Edge
* Firefox
* Safari

---

# Local Setup

## Step 1

Extract the ZIP package.

## Step 2

Keep the folder structure unchanged.

Do not move:

```text
assets/
css/
js/
docs/
```

outside the project.

## Step 3

Open:

```text
index.html
```

inside your browser.

The site will work immediately.

# Before Publishing

Complete the following:

✓ Replace business name

✓ Replace logo

✓ Replace favicon

✓ Replace images

✓ Configure contact form

✓ Update social links

✓ Update pricing

✓ Update sitemap.xml

✓ Update robots.txt

✓ Update site.webmanifest

✓ Test mobile layout

✓ Test tablet layout

✓ Test desktop layout

✓ Verify all navigation links

✓ Verify contact form submissions

✓ Verify thank-you page

---

# Launch Checklist

Before going live:

✓ Domain connected

✓ SSL certificate active

✓ Contact form tested

✓ Images optimized

✓ Open Graph image updated

✓ Sitemap submitted to search engines

✓ Robots.txt verified

✓ 404 page tested

✓ Mobile navigation tested

✓ Footer links verified

---

# Troubleshooting

## CSS Is Missing

Verify:

```text
css/styles.css
css/tablet.css
css/mobile.css
```

exist and were uploaded correctly.

---

## Images Do Not Load

Check:

* File names
* Folder paths
* Upload completion

---

## Contact Form Does Not Work

Verify:

* Provider setup
* Form action URL
* Form field names
* Redirect configuration

---

## Navigation Links Fail

Verify:

* href values
* Page filenames
* Folder structure
