# WorldView Global Lite

WorldView Global Lite is a premium one-page static HTML website designed for global intelligence, travel insight, consulting, location analytics, and international business services.

The template features a cinematic Earth backdrop, glassmorphism-inspired design, responsive layouts, animated interactions, and complete documentation for easy customization and deployment.

No frameworks, build tools, package managers, or server-side software are required.

---

# Features

* Premium one-page website design
* Animated Earth background with atmospheric effects
* Glass-style cards and modern interface design
* Fully responsive desktop, tablet, and mobile layouts
* Mobile navigation menu with accessibility support
* Contact form ready for Formspree, Netlify Forms, Getform, or custom endpoints
* Dedicated Thank You page
* Custom 404 page
* SEO-ready structure
* Sitemap included
* Robots file included
* Web App Manifest included
* Beginner-friendly documentation

# Quick Start

## 1. Download The Project

Extract the template files to a local folder.

## 2. Open The Website

Open:

```text
index.html
```

directly in your browser.

## 3. Customize The Content

Update:

* Business name
* Text content
* Contact information
* Logo
* Images
* Colors

## 4. Connect The Contact Form

Choose a provider:

* Formspree
* Netlify Forms
* Getform
* Custom Backend

See:

```text
docs/form-setup-guide.md
```

for setup instructions.

## 5. Publish The Site

Upload the project to your preferred hosting provider.

* Netlify
* Vercel
* Cloudflare Pages
* GitHub Pages
* cPanel Hosting
* Shared Hosting


Including:

```text

favicon.svg
```

Edit the CSS variables located at the top of:

```text

```

## Adjust Responsive Layouts

Responsive styles are separated into:

```text
css/tablet.css

```
