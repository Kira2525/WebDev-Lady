# WorldView Global Lite Setup Guide

## Welcome

Thank you for purchasing WorldView Global Lite.

WorldView Global Lite is a fully static website built with:

* HTML
* CSS
* JavaScript

No frameworks, build tools, package managers, or server-side software are required.

You can edit the site with any code editor and publish it to almost any hosting provider.

# Local Setup

## Step 1

Download the project.

## Step 2

Extract the ZIP file if necessary.

## Step 3

Keep the folder structure intact.

Example:

```text
WorldViewGlobal-Lite/
│
├── index.html
├── thank-you.html
├── 404.html
│
├── assets/
├── css/
├── js/
└── docs/
```

Do not move files outside their folders.

# Troubleshooting

## Images Missing

Verify:

```text
assets/
```

was uploaded correctly.

---

## Styles Missing

Verify:

```text
css/styles.css
css/tablet.css
css/mobile.css
```

were uploaded.

---

## JavaScript Not Working

Verify:

```text
js/script.js
```

exists on the server.

---

## Form Not Working

Review:

```text
docs/form-setup-guide.md
```

and test with your chosen provider.
