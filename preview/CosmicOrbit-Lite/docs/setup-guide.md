# Cosmic Orbit Lite Setup Guide

## Welcome

Thank you for purchasing Cosmic Orbit Lite.

Cosmic Orbit Lite is a premium one-page astronomy website template designed for observatories, astronomy clubs, telescope experiences, science centers, educational programs, and stargazing events.

The Lite edition delivers a streamlined experience while maintaining the visual style and branding flexibility of Cosmic Orbit Pro.

No frameworks, package managers, build tools, or server-side software are required.

# Step 1: Open The Template

1. Extract the template package.
2. Open the project folder.
3. Launch your preferred code editor.
4. Open:

```text
index.html
```

for an immediate preview.

No installation is required.
