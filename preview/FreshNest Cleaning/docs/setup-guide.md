# FreshNest Cleaning Co. Setup Guide

Thank you for purchasing the **FreshNest Cleaning Co. Website Template**.

This guide will walk you through setting up your website.

---

# Requirements

You only need:

* A web browser (Chrome, Edge, Firefox, Safari, etc.)
* A code editor (recommended: Visual Studio Code)
* A web hosting account (when you're ready to publish)

No frameworks, databases, or special software are required.

# Step 1 - Extract the Template

If your template is downloaded as a ZIP file:

1. Right-click the ZIP file.
2. Select **Extract All**.
3. Open the extracted folder.

---

# Step 2 - Open the Website

Open **index.html** in your web browser.

You should see the complete FreshNest website.

---

# Step 3 - Edit the Website

Open the project folder in your preferred code editor.

Recommended:

* Visual Studio Code
* Sublime Text
* Notepad++
* Cursor

Edit the following files as needed:

| File           | Purpose              |
| -------------- | -------------------- |
| index.html     | Main website content |
| css/styles.css | Desktop styling      |
| css/tablet.css | Tablet styling       |
| css/mobile.css | Mobile styling       |
| js/script.js   | Hamburger menu       |

---

# Step 4 - Replace Demo Content

Update:

* Business name
* Phone number
* Email address
* Services
* Pricing
* Reviews
* FAQ
* Images
* Logo

---

# Step 5 - Replace Images

Open the **assets** folder.

Replace the demo images with your own.

Recommended image sizes:

| Image          | Recommended Size |
| -------------- | ---------------: |
| Hero Image     |      1920 × 1080 |
| Gallery Images |       1200 × 900 |
| Logo           |        200 × 200 |
| Favicon        |          32 × 32 |
| App Icon       |        192 × 192 |
| App Icon       |        512 × 512 |

If you change filenames, update the HTML or CSS to match.

---

# Step 6 - Customize Colors

Open:

```text
css/styles.css
```

Go to:

```css
01. ROOT VARIABLES
```

Change your brand colors there.

---

# Step 7 - Configure the Contact Form

The included form is a demo.

Replace the demo form with your preferred service.

Popular options include:

* Formspree
* Netlify Forms
* Getform
* Basin
* PHP Mail
* Your CRM

---

# Step 8 - Test the Website

Before publishing, verify that:

* Navigation works
* Buttons work
* Images load correctly
* Contact form works
* Hamburger menu works on mobile
* Tablet layout looks correct
* Mobile layout looks correct
* Thank You page loads
* 404 page loads

---

# Step 9 - Upload to Your Web Host

Upload **every file and folder** while keeping the same folder structure.

```text
css/
js/
assets/
index.html
thank-you.html
404.html
robots.txt
site.webmanifest
```

Do not rename or move folders unless you also update the file paths.
