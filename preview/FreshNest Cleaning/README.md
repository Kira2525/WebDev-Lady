# FreshNest Cleaning Co. Website Template

A modern, responsive one-page website template designed for cleaning businesses, maid services, housekeeping companies, janitorial services, and residential cleaning providers.

Built with clean HTML, CSS, and JavaScript for fast performance and easy customization—no frameworks or coding experience required.

---

# Template Features

* Modern one-page layout
* Fully responsive (Desktop, Tablet, and Mobile)
* Sticky navigation
* Mobile hamburger menu
* Hero section with call-to-action buttons
* Trust/Features section
* About section
* Services section
* Pricing section
* Process section
* Gallery section
* Customer reviews
* FAQ section
* Contact form
* Thank You page
* Custom 404 page
* Well-organized and commented code

# Installation

1. Download the template.
2. Extract the ZIP file.
3. Keep all folders together.
4. Open **index.html** in your browser.
5. Replace the demo content with your own.
6. Upload all files to your web hosting provider.
