# Rain Blossom Lite

### Luxury Garden Wedding & Event Landing Page Template

Rain Blossom Lite is a modern, fully responsive HTML5 landing page designed for wedding venues, event venues, gardens, estates, florists, and luxury event businesses.

Built with plain HTML, CSS, and JavaScript, the template is lightweight, fast, and easy to customize without any frameworks or build tools.

---

# Features

* Fully Responsive Design
* Desktop, Tablet & Mobile Layouts
* Single-Page Layout
* Sticky Navigation
* Smooth Scrolling Navigation
* Animated Mobile Menu
* Full Screen Video Hero
* CSS Scroll Animations
* Gallery Section
* Venue Spaces Section
* Packages Section
* FAQ Accordion
* Contact Form

# Customizing the Template

Every customizable section includes **CUSTOMIZE** comments inside the HTML and CSS files.

## Change the Logo

Replace:

```text
assets/images/logo.jpg
```

---

## Change the Favicon

Replace:

```text
assets/images/favicon.png
```

---

## Replace the Hero Video

Replace:

```text
assets/videos/rain-blossom-hero.mp4
```

---

## Replace Images

All website images are located in:

```text
assets/images/
```

Simply replace the files while keeping the same filenames, or update the image paths inside the HTML.

---

## Change Your Business Name

Search for:

```text
Rain Blossom
```

Replace it with your own business name.

---

## Change Your Tagline

Search for:

```text
Garden Weddings & Events
```

Replace it with your own tagline.

---

## Edit Website Text

Open **index.html** and replace the demo content with your own.

Examples include:

* Headlines
* Paragraphs
* Venue descriptions
* Packages
* Gallery captions
* Testimonials
* FAQ
* Contact information

---

## Update Contact Information

Search for:

```text
(555) 019-2840
hello@rainblossom.com
Meadowbrook Valley
```

Replace them with your own business details.

---

## Change Social Media Links

Near the bottom of each page, replace the demo links:

```text
https://facebook.com
https://instagram.com
https://pinterest.com
https://tiktok.com
```

with your own social media profiles.

---

## Change Colors

Open:

```text
css/style.css
```

At the top of the file you'll find the theme variables.

Example:

```css
:root {
  --forest-dark:
  --forest:
  --leaf:
  --gold:
  --cream:
}
```

Changing these values updates the colors throughout the entire website.

---

* Netlify Forms

* Your own backend
