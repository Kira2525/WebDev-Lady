# 2. Change Your Business Name

Search the project for:

```

```

Replace it with your own business name.

Example:

```
Rain Blossom

↓

Evergreen Estate
```

---

# 3. Replace the Logo

Replace:

```
assets/images/logo.jpg
```

Recommended:

* PNG or JPG
* Transparent background (PNG recommended)
* Approximately 300px wide

---

# 4. Change the Favicon

Replace:

```
assets/images/favicon.png
```

Recommended sizes:

* 32×32
* 192×192
* 512×512

---

# 5. Replace Images

All images are located inside:

```
assets/images/
```

You can:

* Keep the same filenames

or

* Change the filenames inside **index.html**

---

# 6. Replace the Hero Video

Replace:

```
assets/videos/rain-blossom-hero.mp4
```

Recommended:

* MP4
* 1080p
* Under 20 MB
* 15–30 seconds
* Muted
* Landscape format

---

# 7. Change Colors

Open:

```
css/style.css
```

Near the top you'll find:

```css
:root {

  --forest-dark:
  --forest:
  --leaf:
  --gold:
  --cream:
  --black;

}
```

Changing these variables updates the colors throughout the website.

# 8. Edit Website Content

Open:

```
index.html
```

Replace the demo content with your own.

Examples include:

* Business name
* Headlines
* Paragraphs
* Venue description
* Services
* Packages
* Gallery
* Testimonials
* FAQ
* Buttons

Every editable section is marked with:

```
CUSTOMIZE:
```

to make it easy to find.

---

# 9. Update Navigation

Rain Blossom Lite is a **single-page website**.

Navigation links scroll visitors to each section of the homepage.

Example:

```html
<a href="#about">About</a>
<a href="#gallery">Gallery</a>
<a href="#contact">Contact</a>
```

You can rename, remove, or reorder the navigation items.
