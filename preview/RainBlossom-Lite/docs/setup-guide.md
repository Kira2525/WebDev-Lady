# Rain Blossom Lite

# Setup Guide

Thank you for purchasing the **Rain Blossom Lite** website template!

This guide will help you set up your website and prepare it for launch.

---

# Requirements

You only need:

* A web hosting account
* A domain name (optional)
* A code editor (Visual Studio Code recommended)
* A modern web browser

No frameworks, package managers, or build tools are required.

---

# Folder Structure

```text
RainBlossom-Lite/
```

---

# Step 1

## Extract the Template

If the template is downloaded as a ZIP file:

* Right-click the ZIP file.
* Select **Extract All**.

You should now have the **RainBlossom-Lite** project folder.

---

# Step 2

## Open the Project

Open the project folder using your preferred code editor.

Recommended:

**Visual Studio Code**

---

# Step 3

## Preview the Website

If you're using Visual Studio Code:

1. Install the **Live Server** extension.
2. Right-click:

```text
index.html
```

3. Select:

```text
Open with Live Server
```

Your website will open in your web browser.

---

# Step 4

## Replace the Demo Content

Before publishing, update:

* Business name
* Logo
* Images
* Hero video
* Contact information
* Social media links
* Headings
* Paragraphs
* Gallery images
* FAQ content
* SEO information

See the included **Customization Guide** for detailed instructions.

---

# Step 5

## Replace Images

Replace the demo images located in:

```text
assets/images/
```

You can:

* Keep the same filenames (recommended)

or

* Rename the files and update the image paths inside the HTML pages.

---

# Step 6

## Replace the Hero Video

Replace:

```text
assets/videos/rain-blossom-hero.mp4
```

with your own MP4 video.

Keeping the same filename means no HTML changes are required.

---

# Step 7

## Connect the Contact Form

By default, the contact form redirects to:

```text
thank-you.html
```

To receive real inquiries, connect the form to a service such as:

* Formspree
* Netlify Forms
* Getform
* Basin
* Your own backend

See the included **Form Setup Guide** for step-by-step instructions.

---

# Step 8

## Update SEO

The website includes:

* Page title
* Meta description
* Open Graph tags
* Twitter/X preview tags

Replace the demo content with information for your own business.

---

# Step 9

## Update the Web App Manifest

Open:

```text
site.webmanifest
```

Update:

* Website name
* Short name
* Description
* Theme color
* App icons

---

# Step 10

## Update robots.txt

Open:

```text
robots.txt
```

Replace the demo domain with your own.

Example:

```text
User-agent: *

Allow: /

Sitemap: https://yourdomain.com/sitemap.xml
```

---

# Step 11

## Update sitemap.xml

Replace every instance of:

```text
https://yourdomain.com
```

with your own domain.

Example:

```text
https://example.com
```

---

# Step 12

## Test the Website

Before publishing, verify that:

✔ The homepage loads correctly

✔ The thank-you page loads

✔ The 404 page loads

✔ Navigation links work

✔ Images display correctly

✔ Hero video plays

✔ Contact form works

✔ Mobile menu opens and closes

✔ Desktop layout looks correct

✔ Tablet layout looks correct

✔ Mobile layout looks correct

✔ Social media links work

✔ Footer links work

✔ No broken images

✔ No broken links

---

# Step 13

## Upload to Your Web Host

Upload all files and folders to your hosting account's public directory.

Common folders include:

```text
public_html/
```

```text
www/
```

```text
htdocs/
```

Your hosting provider will tell you which folder to use.
