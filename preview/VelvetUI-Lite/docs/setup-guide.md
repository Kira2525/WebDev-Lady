# Velvet Studio Lite Setup Guide

Use this guide to review the Lite VELVET STUDIO website before handoff or hosting.

## Page Map

The website includes:

* `index.html`
* `thank-you.html`
* `404.html`

## First Review

Open the site locally and move through each section from the primary navigation. Then open `thank-you.html` and `404.html` directly. Check desktop, tablet, and phone widths. On compact screens, the navigation should use the diamond logo button.

## Business Details

Confirm the fictional studio details are consistent:

* Studio name: VELVET STUDIO
* Domain: `https://velvetstudio.example`
* Email: `hello@velvetstudio.example`
* Service and location language
* Social profile URLs
* Footer copyright line

## Contact Flow

The inquiry form routes visitors to `thank-you.html`. For live collection, connect the form to a provider or backend and test the full submission path before accepting inquiries.

## Final Checks

* The one-page navigation scrolls to the correct sections.
* The 404 page is present.
* The thank-you page is present.
* The mobile menu opens, closes, and keeps links readable.
* Copy reads as VELVET STUDIO, not as package instructions.
