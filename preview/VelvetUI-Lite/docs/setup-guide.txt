VelvetUI Lite Setup Guide

1. Open the VelvetUI-Lite folder.
2. Open index.html in your browser.
3. Edit text inside index.html.
4. Edit colors in css/style.css.
5. Edit the animated words in js/script.js.
6. Save your changes and refresh the browser.

This Lite version is built as a one-page starter template.
Need the full multi-page version? Upgrade to VelvetUI Pro.
