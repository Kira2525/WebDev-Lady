# VELVET STUDIO Lite Website

This project contains a streamlined one-page static website for VELVET STUDIO, a fictional interior design studio. It includes supporting `thank-you.html` and `404.html` pages so the contact and error flows are complete.

## Pages

* `index.html` - One-page studio website
* `thank-you.html` - Inquiry confirmation
* `404.html` - Missing page experience

## Structure

* `css/styles.css` - Main visual system and shared page styles
* `css/tablet.css` - Tablet refinements
* `css/mobile.css` - Compact navigation and mobile refinements
* `js/script.js` - Navigation, active section state, FAQ, reveal motion, form redirect, and canvas effects
* `assets/` - Logo, favicon, social artwork, and editorial imagery
* `docs/` - Website handoff, launch, hosting, form, and image notes

## Local Review

Open `index.html` in a browser, or serve the folder with a local static server. Review the one-page navigation, contact form route, thank-you page, 404 page, and compact navigation at tablet and phone widths.

## Launch Notes

The metadata uses `https://velvetstudio.example` as the fictional business domain. Update it only when a real domain is assigned. The inquiry form currently routes to `thank-you.html`; connect a form provider or backend before collecting real inquiries.

## Readiness Checklist

* Confirm `index.html`, `thank-you.html`, and `404.html` load.
* Confirm all section links scroll correctly.
* Confirm the diamond menu opens and closes on smaller screens.
* Confirm form routing works.
* Confirm all referenced images exist.
