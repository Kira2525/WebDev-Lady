# Setup Guide

## Overview

Abyssal Blue Lite is a static one-page HTML template. No build tools or package installation are required.

## Included Structure

- `index.html`
- `404.html`
- `site.webmanifest`
- `css/`
- `js/`
- `images/`
- `docs/`

## Quick Start

1. Open `index.html` in a browser to preview the Lite version.
2. Update the content in each anchor section:
   - `#home`
   - `#features`
   - `#about`
   - `#services`
   - `#gallery`
   - `#faq`
   - `#contact`
3. Replace demo images in the `images/` folder.
4. Update metadata and contact details before publishing.

## Recommended Pre-Sale Check

- Verify every anchor link scrolls to the correct section
- Test the mobile menu
- Check image loading paths
- Review text wrapping on mobile
- Replace any placeholder contact details
