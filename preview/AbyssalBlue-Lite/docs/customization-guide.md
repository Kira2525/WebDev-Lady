# Customization Guide

## Main Editing Areas

### Content

Edit `index.html` to change:

- hero headline and CTA text
- feature blocks
- about copy
- package previews
- gallery captions
- FAQ text
- contact details

### Styles

Edit `css/styles.css` for:

- colors
- glass card treatment
- spacing
- typography
- section layouts

Edit `css/mobile.css` for:

- mobile menu behavior
- stacked layouts
- smaller spacing and typography adjustments

### JavaScript

Edit `js/main.js` if you want to change:

- hero slider timing
- mobile navigation behavior
- bubble and fish animation frequency
- active anchor highlighting

## Best Customization Workflow

1. Swap the brand name and contact details first.
2. Replace demo imagery with your own licensed ocean or travel imagery.
3. Update the service cards and price points to match your niche.
4. Review the FAQ section so it reflects a real buyer use case.
5. Replace the placeholder metadata URLs before launch.
