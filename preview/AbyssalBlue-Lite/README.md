# Abyssal Blue Lite

Abyssal Blue Lite is a premium one-page HTML website template designed for dive operators, marine attractions, ocean adventure brands, aquariums, wildlife organizations, and tourism businesses that want a polished online presence with simple customization.

Built with standard HTML, CSS, and JavaScript, Abyssal Blue Lite requires no frameworks, build tools, package managers, or installation process.

## Demo Content Notice

Abyssal Blue Lite includes fictional demonstration content created to showcase the design and functionality of the template.

Before publishing a live website, replace all demo branding, contact information, social media links, imagery, metadata, and starter domain values with your own.

## Features

* Premium one-page website template
* Responsive desktop, tablet, and mobile layouts
* Anchor-based navigation
* Animated ocean background
* Bubble and fish particle effects
* Glass-card design system
* Hero, features, about, services, gallery, FAQ, and contact sections
* Contact-focused call-to-action elements
* Footer social media integration
* SEO-ready page structure and social sharing metadata
* `robots.txt` included
* `sitemap.xml` included
* `site.webmanifest` included
* Custom 404 page
* No build tools required

## Quick Start

1. Open `index.html` in your browser.
2. Replace the logo and demo imagery.
3. Update business information and contact details.
4. Update metadata URLs, sitemap values, and social profile links.
5. Customize colors and typography.
6. Test desktop, tablet, and mobile layouts.
7. Deploy to your preferred hosting provider.

## How To Customize

### Content

Edit:

```txt
index.html
```

to update:

* Business name
* Headlines
* Services
* Gallery content
* FAQ content
* Contact information
* Social links
* Calls to action

### Styling

Edit:

```txt
css/styles.css
```

for:

* Colors
* Typography
* Buttons
* Cards
* Spacing
* Layout styling

Additional responsive adjustments can be made in:

```txt
css/tablet.css
css/mobile.css
```

### JavaScript

Edit:

```txt
js/main.js
```

to customize:

* Ocean effects
* Bubble animations
* Fish animations
* Smooth scrolling
* Mobile navigation behavior
