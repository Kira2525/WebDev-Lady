# Abyssal Blue Lite

Abyssal Blue Lite is a premium one-page HTML website template designed for ocean-focused brands that want a polished launch with a simpler structure than the full Pro edition.

## Recommended Price

Recommended marketplace price: `$59`

## Included Files

- `index.html`
- `404.html`
- `site.webmanifest`
- `css/styles.css`
- `css/mobile.css`
- `js/main.js`
- `images/`
- `docs/setup-guide.md`
- `docs/customization-guide.md`

## What Lite Includes

- One-page layout with anchor navigation
- Hero, features, about, services, gallery, FAQ, contact, and footer sections
- Animated ocean background, particles, bubbles, and fish
- Responsive glass-card design
- Simple, self-contained file structure for faster editing

## Lite vs Pro

Lite is designed as a simpler lower-priced product.

- Lite uses a one-page structure with anchor links instead of multiple pages.
- Lite removes the separate Pro pages such as booking, pricing, gallery, wildlife, contact, FAQ, and thank-you pages.
- Lite keeps the premium underwater visual direction but trims the content depth and feature count.
- Pro is better for buyers who want a fuller site architecture and more page variety.

## How to Customize

1. Edit `index.html` to update copy, offers, contact details, and brand messaging.
2. Replace images in the `images/` folder with your own licensed files.
3. Adjust colors, spacing, and card styling in `css/styles.css`.
4. Update mobile layout behavior in `css/mobile.css` if needed.
5. Replace placeholder `https://example.com` metadata values before publishing.
