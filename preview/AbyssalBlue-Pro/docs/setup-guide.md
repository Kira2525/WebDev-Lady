# Abyssal Blue Pro Setup Guide

## Overview

Abyssal Blue Pro is a premium static HTML website template designed for dive operators, marine tourism businesses, ocean adventure companies, charter operators, and wildlife tourism brands.

No frameworks, build tools, package managers, or installation steps are required.

The template runs using standard HTML, CSS, and JavaScript files and can be deployed directly to most hosting providers.

## Included Pages

```txt
index.html
about.html
wildlife.html
gallery.html
booking.html
contact.html
pricing.html
faq.html
thank-you.html
404.html
```

## Quick Start

1. Replace your logo in `images/logo.svg`.
2. Replace demo photography in `images/`.
3. Update the business name and contact information.
4. Update pricing and package details.
5. Update metadata URLs, sitemap values, and social profile links.
6. Configure the booking and contact forms.
7. Test the website locally.
8. Deploy to your preferred hosting provider.

## Launch Checklist

Before publishing:

* Navigation links work correctly
* CTA buttons point to real destinations
* Package names match across pricing and booking pages
* Contact information is accurate
* Social links are updated
* Forms function correctly
* Thank-you page works correctly
* robots.txt uses the final domain
* sitemap.xml uses the final domain
* Canonical URLs match the intended production paths
* Open Graph URLs and images are updated as needed
* Favicon loads correctly
* Manifest loads correctly
* Mobile navigation functions properly
* Gallery filtering and lightbox work correctly
