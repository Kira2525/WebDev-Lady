=========================================================
1. CHANGE THE BUSINESS NAME
=========================================================

Open each HTML file and search for:

APEX
DETAIL

Replace them with your own business name.

Example:

Elite Auto Spa

or

Superior Mobile Detailing

Also replace the logo letter:

A

with your own first letter.

Example:

E

=========================================================
2. CHANGE WEBSITE COLORS
=========================================================

Open:

css/styles.css

At the top you will find:

:root

Example:

--color-accent
--color-bg
--color-text

Simply replace the color codes.

Example

Gold

#d4af37

Blue

#2563eb

Red

#dc2626

Green

#22c55e

=========================================================
3. CHANGE THE HERO IMAGE
=========================================================

Open

css/styles.css

Look for

--hero-image

Replace the image URL with your own image.

Example:

images/hero.jpg

=========================================================
4. CHANGE LOGO
=========================================================

Replace:

Logo letter

Logo text

Business name

throughout every page.

Search for

logo-text

and

logo-icon

=========================================================
5. CHANGE TEXT
=========================================================

Open any HTML page.

Simply replace the sample text.

Examples

Homepage headline

Service descriptions

Package names

Pricing

Reviews

FAQ

Contact information

Everything is clearly labeled.

=========================================================
6. CHANGE IMAGES
=========================================================

Create a folder named

images

Example

images/interior-detail.jpg

Replace image paths like

https://images.unsplash....

with

images/interior-detail.jpg

Supported formats

jpg
png
webp

Change

Image

Title

Description

Bullet list

Button

9. CHANGE GALLERY

gallery.html

Image

Title

Overlay text

10. CHANGE CONTACT INFORMATION

contact.html

Update

Phone Number

=========================================================
11. CONNECT THE CONTACT FORM
=========================================================

The included form is HTML only.

To receive submissions, connect it to:

FormSubmit

Netlify Forms

Getform

Formspree

or your own backend.

After connecting the form, change

<form>

to include your provider's settings.

=========================================================
12. CHANGE BUTTON LINKS
=========================================================

Every button uses standard HTML links.

Example

href="contact.html"

Replace them with your own pages if needed.

=========================================================

favicon.ico

favicon.png
