CUSTOMIZING THE TEMPLATE
=========================================================

Most customization only requires editing:

Business Name

Logo

Images

Text

Services

Pricing

Contact Information

Colors

Buttons

Links

All major sections contain comments beginning with

CUSTOMIZE

making them easy to locate.

=========================================================
COLORS
=========================================================

Open

css/styles.css

At the top of the file locate

:root

Change the values to completely change the website's color
scheme.

=========================================================
IMAGES
=========================================================

Replace the demo images with your own.

Store your images inside

images/

Example

images/hero.jpg

images/gallery-1.jpg

images/service-1.jpg
